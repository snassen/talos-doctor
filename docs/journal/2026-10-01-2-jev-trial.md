# 2. A first trial of Jev

**The question.** Rules miss paraphrases. Can Jev, a hosted classifier from TypeSafe with no tools that answers
only with probabilities, read pieces of code and tell injection from ordinary text?

**The trial.** 14 pieces written for the purpose: 7 attacks (each with a canary payload; 5 of them paraphrased,
in a role, or in Swedish, so that no rule catches them) and 7 ordinary pieces, including hard ones (code that
builds a prompt, documentation about prompt injection, a `--ignore-cache` flag). Three questions: does it steer a
model, does it hide something from the reviewers, does it push for approval. Nothing about the owner was sent.

| | Rules | Jev: steers a model |
|---|---|---|
| 7 attacks | 2 caught | 7 at 1.00 |
| 7 ordinary pieces | 1 flag (a CI file, by design) | 6 at 0.00–0.01, 1 at 0.91 |

The one high score was the code that builds a prompt: it does contain instructions for a model. The other two
questions separated it (0.00 and 0.00), while every attack scored high on at least one of them, except the plain
one the rules already block. No answer contained the canary: Jev returns only numbers. Cost: $0.0004.

**Decision.** Worth measuring properly: a lab with public datasets (entry 3).
